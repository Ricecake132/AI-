size_5_2를 넣으면 match[1]은 size_5, match[2]는 문자열 5다. 마지막 2는 같은 크기 안에서 입력을 구별한다.

def mac(pattern, kernel):
    total = 0.0
    for row, weights in zip(pattern, kernel):
        for value, weight in zip(row, weights):
            total += value * weight
    return total

바깥 zip은 행을, 안쪽 zip은 한 칸을 짝짓는다. 패턴 실험 탭의 슬라이더를 움직여 현재 칸을 더한 직후의 total을 확인해 보자.

def decide(a, b, labels):
    if not (math.isfinite(a) and math.isfinite(b)):
        raise ValueError("MAC 점수가 유한수 범위를 벗어났습니다.")
    if abs(a - b) < EPSILON:
        return "UNDECIDED"
    return labels[0] if a > b else labels[1]

abs(a-b)가 1e-9 미만이면 동점이다. JSON 모드는 이 판정과 정규화한 expected를 한 번 더 비교해 채점한다.

start = perf_counter_ns()
mac(pattern, kernel)
elapsed += perf_counter_ns() - start

MAC 호출 직전과 직후의 나노초 차이를 더한다. benchmark는 10회 측정 뒤 10과 1,000,000으로 나눠 1회 평균 밀리초를 출력한다.
